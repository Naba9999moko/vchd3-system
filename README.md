# ВЧД-3 цахим мэдээллийн систем

Вагон ашиглалтын депогийн мэдээллийн нэгдсэн систем.

## Үндсэн боломжууд

- Ажилтны бүртгэл
- Админы зөвшөөрлөөр нэвтрэх
- Олон админтай удирдлага
- Үндсэн админ админ томилох, эрх цуцлах
- ГТХАБ мэдээлэл
- Техникийн мэдээлэл
- Цахилгаан тушаал
- ХАБЭА мэдээлэл

## Ашиглах технологи

- Node.js
- Express
- PostgreSQL
- HTML, CSS, JavaScript
